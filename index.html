Responsly Android SDK

Maven repository of com.responsly:sdk. Show Responsly surveys inside your Android app.

1. Add the repository

// settings.gradle.kts
dependencyResolutionManagement {
    repositories {
        google()
        mavenCentral()
        maven { url = uri("https://responsly.github.io/responsly-android-sdk/maven") }
    }
}

2. Add the dependency

// app/build.gradle.kts
dependencies {
    implementation("com.responsly:sdk:1.2.3")
}
